# Fly Heaven

A local, single-fly connectome-based simulation project.

Phase 1 pins and wraps the existing [Fly.exe / MaleCNS Virtual Fly](https://github.com/Ibtisam-Mohammad/Fly.exe) simulator without vendoring it or its data. See [the setup and RTX 3070 benchmark procedure](docs/PHASE-1.md) for provenance, limits, tests, and the manual WSL2 run steps.
